# 恐龙认字大冒险

给 4 岁半男孩玩的认字闯关游戏。只用《小羊上山》第 1–3 级总字表里的字（第 1 级只作复习）。

## 怎么玩
- 直接用浏览器打开 `index.html`（双击即可，不需要网络；跟读 / 大声读的语音识别要联网）。
- 或者在 GitHub 仓库 Settings → Pages 里选 “Deploy from a branch”，选这个分支和根目录 `/`，就有一个网址，平板和电视都能打开。

## 内容
- 40 关，5 个世界（恐龙谷、蓝色大海、云朵天空、火山世界、冰雪王国）：词语 → 短语 → 句子，选项从 3 个加到 5 个，越往后越多形近字（很/狼、我/找、爬/把/爸）和同音字（在/再、门/们，放进句子里选）。
- 每关 9 题：3 道认字、1 道开口说、2 道数学、2 道英语、1 个小游戏。第 4 关小对战，第 8 关大魔王。
- 25 种题型和小游戏：听音选字、看图、拼词、句子填空、句子排序、找不同、孵蛋找字、跳石头、打恐龙地鼠、恐龙对对碰、连一连、恐龙消消乐、拼图（2/4/6/9 块）、按顺序点、大声读、跟读，以及英语 A–I、1–10。
- 数学和动脑（参考《3–6 岁儿童学习与发展指南》4–5 岁目标，难度随世界上升）：数一数（手口一致点数）、拿给恐龙（按数取物）、数字和数量连一连、比多少、小火车排排队（缺了几）、找规律（AB → AAB/ABB → ABC/AABB）、分一分、大小排队、上下前后里、找形状、影子配对、哪个不一样、3×3 小数独、合起来（后面的世界才有 5 以内 / 10 以内加减，用实物）。数字常用汉字“一…十”显示，方位、大小、多少、颜色也用课本里的字，语文和数学一起复习。
- 搭房子：照着样子把积木搭上去，要先搭下面再搭上面；后面的世界只给图纸、积木盒里有颜色相近的干扰块，搭完还要数一数用了几块。搭好的房子住进“恐龙小镇”。
- 游乐场：不用闯关也能玩对对碰、消消乐、拼图，以及全部数学游戏。
- 孵蛋屋：答对题让蛋变暖（普通蛋 30、稀有蛋 55、金蛋 90），蛋会慢慢裂开；满了还要再答 4–6 题帮它破壳。每天可以照顾蛋（盖被子、擦一擦、跟它说话、读给它听）。孵出的恐龙在乐园里喂食长大：宝宝 → 小恐龙 → 大恐龙。
- 家长页（首页右下角，按住 2 秒）：答对答错统计、容易错的字（会自动多出）、解锁关卡、清空存档。

## 文件
- `index.html` 页面和样式；`js/data.js` 词库和关卡；`js/core.js` 存档、语音、音效；`js/games.js` 语文和英语题型；`js/math.js` 数学、逻辑和搭房子；`js/screens.js` 各个页面。
- `assets/` 恐龙插画、场景图、录好的童声（`aud.js`）、Andika 字体。没有录音的句子用浏览器自带的中文朗读。
