# 恐龙认字大冒险

给 4 岁半男孩玩的认字闯关游戏。只用《小羊上山》第 1–3 级总字表里的字。第 1、2 级的字孩子已经会了，不再单独考，只放在词语和句子里。设计思路是“够一够才能够到”，要学、要大人帮，不让孩子一路刷过去，也不让他一直泡在游戏里。

## 怎么玩
- 直接用浏览器打开 `index.html`（双击即可，不需要网络；跟读 / 大声读的语音识别要联网）。
- 网页版：仓库需要是公开的（免费账号的私有仓库不能开 Pages）。Settings → Pages → Source 选 “Deploy from a branch” → 分支选 `claude/dino-word-adventure`，文件夹选 `/ (root)` → Save。一两分钟后打开 https://fugfjohfhgdhiy75-ship-it.github.io/xihe-cen/ 。在 iPhone / iPad 的 Safari 里点“分享 → 添加到主屏幕”，就能像 App 一样全屏打开。

## 内容
- 40 关，5 个世界（恐龙谷、蓝色大海、云朵天空、火山世界、冰雪王国）：第 1–10 关词语，11–25 关短语，26–40 关句子。词库有 113 个词语、67 个短语、62 句句子。
- 一开始就是 4 个选项，干扰项故意找长得像、读音像的（听“小猫”，选项里有“小草、小手”；单字题只考第 3 级新字和很/狼、我/找、在/再这类容易混的字）。看图的题不会出现两个都说得通的答案。连续两关错得很少，下一关自动多一个选项。
- 每关 3 颗心：认真答错扣一颗（翻牌、拼图这类试来试去的不扣）。心用完这一关就结束，列出错的字词请和妈妈一起看，然后进入亲子时间。
- 亲子时间：游戏锁住，给一个线下任务（看书 10 分钟、搭真积木、找 5 个红色的东西、数楼梯、画恐龙、玩“我说你做”……）。倒计时结束后要家长按住按钮确认才能继续；家长也可以按住 3 秒提前结束。连续玩够 20 分钟也会在过关后进入亲子时间。几次心、休息多久、连续玩多久都能在家长页调。
- 每关 9 题：3 道认字、1 道开口说、2 道数学、2 道英语、1 个小游戏。第 4 关小对战，第 8 关大魔王。
- 25 种题型和小游戏：听音选字、看图、拼词、句子填空、句子排序、找不同、孵蛋找字、跳石头、打恐龙地鼠、恐龙对对碰、连一连、恐龙消消乐、拼图（2/4/6/9 块）、按顺序点、大声读、跟读，以及英语 A–I、1–10。
- 数学和动脑（参考《3–6 岁儿童学习与发展指南》4–5 岁目标，难度随世界上升）：数一数（手口一致点数）、拿给恐龙（按数取物）、数字和数量连一连、比多少、小火车排排队（缺了几）、找规律（AB → AAB/ABB → ABC/AABB）、分一分、大小排队、上下前后里、找形状、影子配对、哪个不一样、3×3 小数独、合起来（后面的世界才有 5 以内 / 10 以内加减，用实物）。数字常用汉字“一…十”显示，方位、大小、多少、颜色也用课本里的字，语文和数学一起复习。
- 搭房子：照着样子把积木搭上去，要先搭下面再搭上面；后面的世界只给图纸、积木盒里有颜色相近的干扰块，搭完还要数一数用了几块。搭好的房子住进“恐龙小镇”。
- 游乐场：不用闯关也能玩对对碰、消消乐、拼图，以及全部数学游戏。
- 孵蛋按天算：开局先选一只恐龙宝宝当伙伴，再领一颗蛋。普通蛋至少 3 天（60 🔥）、稀有蛋 5 天（120 🔥）、金蛋 7 天（200 🔥），每天答题能加的温度有上限，照顾蛋（盖被子、擦一擦、跟它说话、读给它听）另外加。满了还要再答 5–8 题帮它破壳。孵出的恐龙在乐园里喂食长大：宝宝 → 小恐龙 → 大恐龙。
- 家长页（首页左上角“⚙️ 家长”，按住 2 秒）：答对答错统计、容易错的字（会自动多出）、解锁关卡、清空存档。

## 文件
- `index.html` 页面和样式；`js/data.js` 词库和关卡；`js/core.js` 存档、语音、音效；`js/games.js` 语文和英语题型；`js/math.js` 数学、逻辑和搭房子；`js/screens.js` 各个页面。
- `assets/` 恐龙插画、场景图、录好的童声（`aud.js`）、Andika 字体。没有录音的句子用浏览器自带的中文朗读。
